# 三個世界

## 1. 終端機內部（`env.terminal_space()`）

把「螢幕上的一行字」變成一個可以走進去的空間。參考：`../benchmark/frames/t_0.2.jpg`、`t_5.0.jpg`、`t_9.5.jpg`、`t_16.6.jpg`。

| 元素 | 做法 | 數值 |
|---|---|---|
| 地面 | 光滑深色（`dark_gloss`，粗糙度 0.28），看得到角色倒影和一道冷白地面高光 | z = 0，角色沿 +X 走 |
| 背牆 | 深色（`#191d24`），在 y = 3.2 | |
| 金屬導軌 | 三條細長的金屬條：前方地面、背牆 2.1 cm、6 cm 高 | `metal('Rail')` |
| 程式碼 | **圓角膠囊**（`code_rows`）：隨機長度的 token、縮排、空行、6 % 綠色 token，自發光灰 `#9aa4ae` | 近排 14 行在背牆，遠排 20 行在 y = 18 形成視差 |
| 提示符 `>` | 兩根倒角長條組成的 V（`chevron`），自發光淺灰 | 在角色左側、眼睛高度 |
| 游標 | 橘色黏土長條，帶微弱自發光（`cursor`），1:3 比例 | 閃爍用 `env.blink(obj, ctx.beat, 起拍, 止拍)` |

**原則**：永遠不寫真的文字。程式碼抽象成膠囊條，任何距離都讀得出「這是程式碼」，又不會出現亂碼。

## 2. 房間（`env.room()`）

只出現 1 秒（S02），作用是讓觀眾記住「深夜還在寫程式的房間」並完成第一次尺度揭示。

- 桌面深色、顯示器（`env.monitor()`）滿屏膠囊程式碼，是唯一的主光。
- 鍵盤在前景，**全部沉睡**（`glow=0`、`lights=False`、`cell=0.17` 省面數）。
- 窗戶：深藍夜空自發光平面＋一排松樹剪影（`pine`，堆疊方塊）。
- Clawd 是螢幕底部一個自發光的橘點（`static_mesh(px=0.07)` + 自發光材質）。

## 3. 桌面與顯示器（鍵盤段）

`common.keyboard_set()`：鍵盤在原點，桌面 z = −1.6，顯示器螢幕中心 (0, 24, 21)、56 × 32 cm，前表面 y = 23.95。

- 螢幕上有程式碼膠囊；結尾（S17）加上 `env.screen_sprite()`：自發光的 2D 像素 Clawd、左邊 `>`、右邊游標（`cursor_blink=(ctx.beat, 起拍, 止拍)`）。
- 角色穿出螢幕的位置要在螢幕下半部、鍵盤後排的正上方。

## 4. 草原（`env.meadow()`）

鍵帽裡的世界，**寫實尺度**：角色 1.5 cm，草葉 2.2–6.5 cm，雛菊莖 4.5–8 cm。角色只到草的腳踝，這就是「它很小」的感覺。參考：`t_31.5.jpg`、`t_38.5.jpg`、`t_45.0.jpg`。

| 元素 | 做法 |
|---|---|
| 地面 | 半徑 140 的圓盤，緩起伏（`ground_height(x, y)`，所有東西都用它貼地）；點屬性 `density`：鏡頭焦點附近 1，往外降到 0.12，池塘裡 0 |
| 草 | 10 種草葉（彎曲、漸細、微扭轉、0–2 顆露珠，UV.y 根部深綠到葉尖亮綠，35 % 透光），Geometry Nodes 散佈（`scatter_group`），密度 16–22／cm² |
| 花 | 4 種雛菊（16 片白花瓣＋黃心）、藍色小花，密度 0.05 |
| 池塘 | 地面挖空（density 0）＋深色水面圓盤，位置來自 `layout.pond` |
| 遠樹 | 260–420 cm 外一圈圓潤樹冠剪影，被大氣霧化成藍灰 |
| 雲 | 半徑 3500 的大球，噪聲遮罩的白色自發光雲（`sky_dome`） |
| 天空與陽光 | `lighting.rig_meadow()`：物理天空 + 太陽（仰角 38°、方位 135°）+ 世界霧 |

**焦點區域**（`dense_center`、`dense_r`）每個鏡頭都要設在角色附近：草只在看得到的地方密，其他地方稀疏，渲染才跑得動。

**樹**（`voxel.tree` + S12 的 `grow_tree`）：樹幹是 3 × 3 的深色方柱（樹皮材質有明暗斑）、3 條斜伸的枝、主樹冠半徑 8 格加枝端小樹冠；樹冠是亮綠色方塊，每塊亮度隨機。**樹一定長在種子的位置**（`layout.tree == layout.seed`）。

## 5. 一致性規則

- 同一個世界的每個鏡頭都呼叫同一個 `*_set()` 函式、用同樣的種子，只改焦點區域。
- 地標（池塘、樹、巨人的位置）只能從 `layout` 讀。
- 太陽方向全段固定（方位 135°）；改了就整段一起改。
