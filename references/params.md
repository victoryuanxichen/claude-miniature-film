# 參數卡、分鏡、shots.json

## 1. 參數卡格式

第 0 步發給使用者確認。每項都要有推薦值和一句理由，使用者沒提到的也要填。

```markdown
## 推薦參數卡

| 項目 | 推薦 | 理由 |
|---|---|---|
| 片名／子資料夾 | claude-keycap-world → ./claude-keycap-world/ | |
| 一句話 | 游標活過來，走進鍵帽裡的世界，種出一群自己，再回到終端機 | |
| 源點符號 | 終端機橘色游標 | 最小、最日常、和角色同色 |
| 世界 | 終端機內部 → 鍵盤 → 鍵帽裡的草原 | 兩次尺度翻轉 |
| 角色 | Clawd（Claude Code 像素小怪），1.5 cm 寬 | 品牌識別 |
| 片長／鏡頭數 | 60 s／18 鏡 | 對標基準片 |
| 畫幅／解析度 | 16:9，1920×1080（最終）；預覽 960×540 | 橫屏敘事片 |
| fps | 30（每拍 15 幀） | 卡拍整除；要電影感可用 24（每拍 12 幀） |
| BPM | 120 | 每拍 0.5 s、每小節 2 s，切點好算 |
| 結尾 | 3D 角色看著螢幕上的 2D 自己，游標再次閃爍，切黑 | 閉環 |
| 渲染路線 | 本機：建場景＋previs 靜幀；正式：外部 GPU，EEVEE 為主、鍵帽特寫 Cycles | 本機效能不足以長時間渲染 |
| 配樂 | 120 BPM 輕快電子鋼琴，40 s 處重拍；使用者提供或授權曲 | Claude 不能試聽 |
| 交付到哪一步 | 鏡頭腳本＋.blend＋英雄幀靜圖 | 使用者指定 |
```

**時間預算**：60 秒片至少 14 個鏡頭；每個「形變」或「奇觀」至少 4 秒。使用者要的片長太短時，在卡上說明並給建議長度。

## 2. STORYBOARD.md

模板在 `template/STORYBOARD.md`，完整範例在 `examples/claude-keycap-world/STORYBOARD.md`。必須包含：

1. **一句話概念**
2. **母題清單**：每次出現的時間、形態、身分
3. **尺度階梯**（story.md 第 3 節的樹狀圖）
4. **色彩腳本**：每段的主色調和亮度
5. **能量曲線**：亮度和響度兩條
6. **分鏡表**：每個鏡頭一列

| 欄位 | 寫什麼 |
|---|---|
| 鏡號、時間 | S05 11.5–17.5（6.0 s） |
| 景別／鏡頭 | MS → CU，35→50 mm，f/4→2.8 |
| 運鏡 | 跟降 → 環繞 |
| 畫面 | 發生的事，按時間順序 |
| 觀眾要讀懂的一件事 | 「它走出了螢幕，踩到的鍵會醒過來」 |
| 角色表演 | 好奇歪頭、眨眼、蹦跳 |
| 光 | 螢幕冷光為主，鍵帽亮起時腳底被染暖 |
| 轉場出 | 硬切（卡拍）／動作匹配／介面穿越 |
| 聲音 | 落地「咚」＋水聲；12 s 主旋律進 |
| 英雄幀 | 13.4、16.0（要先渲染確認的瞬間） |

## 3. shots.json 欄位

```jsonc
{
  "title": "Claude Keycap World",        // 片名
  "slug": "claude-keycap-world",         // 輸出檔名
  "logline": "…",                        // 一句話
  "fps": 30, "bpm": 120,
  "res": [1920, 1080],
  "handles": 6,                          // 每個鏡頭前後多算的幀數（剪輯餘量、動態模糊）
  "unit_scale": 0.01,                    // 1 BU = 1 cm
  "audio": {"music": "assets/music.wav", "offset": 0.0},
  "layout": {                            // 跨尺度共用的正方形版圖（u 向右、v 向後，0–1）
    "pond": [0.40, 0.60, 0.10],          //   u, v, 半徑
    "tree": [0.617, 0.40], "seed": [0.617, 0.40], // 樹必須長在種子的位置
    "hill": [0.12, 0.85], "clawd_land": [0.6, 0.35], "giant": [0.70, 0.45]
  },
  "state": {                             // 跨鏡頭保留的世界狀態
    "hero_key": "R3K12",                 //   主角鍵帽（鍵號 = R<列>K<該列第幾顆>）
    "keyboard_seed": 7,
    "lit_trail": [["R1K11", 13.4], …],   //   [鍵號, 全片秒數]：在那一刻被點亮，之後一直亮
    "all_awake": 52.6                    //   全部醒來的時間
  },
  "shots": [
    {"id": "S05", "start": 11.5, "end": 17.5,
     "module": "s05_exit_landing",       // shots/ 底下的模組名
     "hero": [0.3, 2.0, 4.6],            // 英雄幀（鏡頭內秒數，從切入點算）
     "offbeat": false,                   // 結尾切點不在拍點上（動作驅動）時設 true
     "ref": "S05",                       // 驗收時對照的基準鏡頭（預設同鏡號；新題材指向最接近的基準鏡頭）
     "title": "…", "camera": "…", "transition_out": "…"}
  ]
}
```

**規則**：

- `start`／`end` 是全片秒數，鏡頭首尾相接（`edit.py check` 會檢查）。
- 鏡頭腳本裡用 `ctx.g(全片秒數)` 或 `ctx.beat(n)` 取幀，不要自己算。`ctx.f(t)` 是「切入後 t 秒」。
- `lit_trail` 的時間要和鏡頭腳本裡角色落地的時間一致（例如 `C.hop(..., g(16.0), ...)` 對應 `["R2K12", 16.0]`），`common.wake(ctx, kb)` 會自動在落地那一幀點亮並按下鍵帽。
- **版圖是正方形**：寫實草原裡 1 單位 = 120 cm；放進寬鍵（Enter 2.25u）時佔中間的正方形區域，左右兩側是延伸的草地。擺地標前先算構圖：S10 要讓種子游標在 75 mm 畫面裡（角色身後偏右），S16 的正俯視要同時框到樹冠、巨人和池塘一角。
- 新增會跨鏡頭保留的狀態時，加進 `state`，並在 `ctx` 或 `common.py` 裡寫讀取函式。
