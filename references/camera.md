# 鏡頭語言

## 1. 相機的構造

每個鏡頭一台相機加一個**瞄準點**（Empty，Track To 約束），景深預設對焦在瞄準點上。所以每個運鏡都只是兩條位置曲線：相機在哪、看哪裡。

```python
cam, tgt = CAM.camera('Cam', loc, target, lens=50, fstop=2.8)
CAM.move(cam, [(f0, p0), (f1, p1, 'expo'), …])      # 相機路徑（第三項 = 離開這一點的緩動）
CAM.move(tgt, [(f0, q0), (f1, q1)])                  # 瞄準點路徑
CAM.follow_bake(tgt, rig.root, f0, f1, offset=(0, 0, 0.7), smooth=8)   # 有延遲地跟著角色
```

## 2. 微縮感的三個預設

1. **低機位**：80 % 的鏡頭架在角色眼睛高度（0.6–1.0 cm）或更低。俯拍只用在「展示世界」（鍵盤跳躍、正俯視）。
2. **淺景深**：1 BU = 1 cm 時物理景深本來就淺。起始值：特寫 f/1.8–2.8，中景 f/2.8–4，遠景 f/5.6–8。
3. **前景遮擋**：幾乎每個鏡頭前景都要有東西虛化（鍵帽、草葉、程式碼行、提示符）。

## 3. 焦距

| 焦距 | 用途 |
|---|---|
| 24–28 mm | 尺度反轉（仰望天空）、強透視的橫移（穿光膜）、大拉出開頭 |
| 35 mm | 環境與角色並重（落鍵、樹長大、結尾） |
| 50 mm | 標準中景、側面跟拍 |
| 70–85 mm | 特寫、微距草叢（前景草完全融化） |

## 4. 運鏡庫

| 運鏡 | 函式 | 用在 | 意圖 |
|---|---|---|---|
| 緩慢後拉＋環繞 | `move` + `orbit` | 誕生 | 讓觀眾看到深度出現 |
| 靜止大遠景 | 只放相機 | 房間 | 尺度揭示 |
| 橫移跟拍 | `move`（直線）+ `follow_bake(tgt)` | 穿光膜、空白鍵 | 旅程感 |
| 跟降 | `follow_bake(tgt)`，相機緩降 | 穿出螢幕、從天而降 | 換世界時都是「掉下去」 |
| 高角度跟拍 → 升起拉遠 | `move` 三點 | 鍵盤跳躍 | 展示足跡 |
| 甩鏡下壓 | `whip(tgt, f0, f1, 目標)` + 動態模糊 | 跳進鍵帽 | 動作驅動的轉場 |
| 貼地微距緩推 | `move` 小距離 + `handheld` | 草原 | 沉浸 |
| 後拉＋上搖 | `move(cam)` + `move(tgt)` 往上 | 樹長大 | 跟著生長方向 |
| 靜止長鏡頭 | 幾乎不動 | 堆砌巨人 | 奇觀需要穩定畫框 |
| 快速升到正俯 | `move` 用 `'expo'` | 巨人 → 俯視 | 為透鏡揭示擺好版圖 |
| 一鏡到底大拉出 | 6 點的 `move` | 結尾 | 串起所有尺度 |

其他工具：`rack(cam, [(f, 距離)])` 拉焦、`fstop_keys`、`lens_keys`（變焦）、`handheld(cam, tgt, f0, 位置幅度, 瞄準幅度)`。

## 5. 規則

- **相機永遠在呼吸**：完全靜止的鏡頭也加極小的 `handheld`（0.005–0.01），除非刻意要「凍結」。
- **每個運動都有緩動**：`move` 預設 `ease`（貝茲曲線）；快速的用 `expo`；跟拍用 `follow_bake` 的平滑。
- **跟拍要有延遲**：`smooth` 6–12 幀；相機比角色晚一點點，畫面才有重量。
- **鏡頭方向延續**：接縫兩側的運動方向一致（跳出畫面右上 → 下一鏡從左下進來）。
- **俯拍的瞄準點**要比相機低，並在 Y 方向偏一點點，否則 Track To 會翻轉。
- **構圖**：角色不要老在正中；三分法；奇觀鏡頭把角色放在前景一側（觀眾透過它看）；留出動作前進方向的空間。
- **景別要變**：連續兩個鏡頭不要同景別同焦距。
