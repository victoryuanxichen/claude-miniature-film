# 轉場

## 1. 核心原則：每次換世界都穿過一個介面

基準片沒有一個溶解、沒有一個花俏的轉場。換世界時，角色**穿過一個物理介面**，介面產生反應（光、波紋、水花）。轉場就是故事的一部分，不是剪輯技巧。

| 從 → 到 | 介面 | 反應 |
|---|---|---|
| 終端機 → 鍵盤 | 螢幕玻璃 | 穿過時是一道光膜；穿出後玻璃上泛起同心圓 |
| 鍵盤 → 草原 | 鍵帽頂面 | 表面像水一樣起漣漪、鍵帽閃亮 |
| 草原 → 鍵帽外 | 透鏡 | 光點 → 圓環 → 玻璃球，球裡是體素微縮版 |
| 鍵帽 → 鍵盤 | 鍵帽頂面 | 爆閃白光、方塊四散 |

## 2. 六種轉場的做法

### ① 形變（一個鏡頭內，不剪）
游標 → 2D → 體素 → 實體（S01）。見 [fx.md](fx.md) 第 1 節。相機在變化期間要動（環繞），觀眾才看得到深度出現。

### ② 尺度揭示硬切
特寫直接切大遠景，主角變成一個點（S01 → S02，8.0 s）。**一秒就夠**。切點卡拍。下一鏡（S03）再切回主角。

### ③ 穿膜 + 動作匹配
S04：側面跟拍，角色走進光膜（`FX.membrane` + `membrane_pass`），身體被光膜切開。S05 從螢幕外面接同一個瞬間：角色從玻璃走出來，背後泛起同心圓（`FX.ripple(normal='Y')`）。**兩邊的運動方向和速度要延續**。

### ④ 撞擊漣漪（動作驅動，不卡拍）
S08：大跳 → 鏡頭甩下（`CAM.whip`）→ 角色撞進鍵帽頂面：漣漪（`FX.ripple(normal='Z')`）＋ 鍵帽閃到 2.6 ＋ 角色縮小沉入 → 在撞擊後 0.3 秒切（28.37 s，`"offbeat": true`）→ S09 從天空落下。

### ⑤ 透鏡揭示（一鏡到底的尺度翻轉）
S16 結尾到 S17 開頭，六拍（逐幀參考 `../benchmark/transitions/g_lens_reveal.jpg`）：

| 拍 | 時間 | 做法 |
|---|---|---|
| 拔高 | 51.0–51.3 | 相機 `expo` 快速升起，前景樹冠高速掠過畫面（自然的擦除） |
| 俯視定格 | 51.3–51.6 | 正俯視：樹冠在左、巨人在右、池塘在左上。**這就是微縮版的版圖** |
| 種子光點 | 51.6–51.8 | 樹冠和巨人之間一個白色光點 → 圓環（`FX.lens_bubble` 的 glint） |
| 透鏡 | 51.7–51.9 | 圓環變成玻璃球透鏡 |
| 硬切 | 51.90 | 切到 S17：透過鍵帽頂面看下去的體素微縮版，**版圖完全一致**，多了樹、小 Clawd、小巨人 |
| 一路拉出 | 52.0–54.6 | 看到鍵帽四壁 → 鄰鍵依序亮起 → 角色從鍵帽彈出 → 整把鍵盤 |

成立的前提：版圖連貫（`layout`）、進出同一顆鍵、改變被保留、兩種解析度（裡面寫實、外面體素）。

### ⑥ 動作匹配硬切
同一個動作換機位接（穿膜內 → 穿膜外、跳 → 落）。切點放在動作中段，兩邊各留 2–3 幀重疊。

## 3. 入場和出場是鏡像

| | 入場（鑽進去，S08） | 出場（拉出來，S16–S17） |
|---|---|---|
| 方向 | 從上往下，鏡頭下壓 | 從下往上，鏡頭升起 |
| 介面 | 鍵帽表面漣漪 | 玻璃球透鏡 |
| 切換後 | 從天空落到寫實草原 | 從俯視寫實切到體素微縮 |
| 音樂 | 收小，進入留白段 | 高頻閃爍上行掃頻 |

## 4. 時間

- 硬切在拍點上（`ctx.beat(n)`）；動作驅動的切點標 `"offbeat": true`，但動作高點仍要卡拍（撞擊在 28.0 s）。
- 每個鏡頭前後有 `handles`（6 幀）：運動要延續穿過切點，不要在切點停下。
- 甩鏡、快速升降要開動態模糊（`look`／`final`／`cycles` 預設都開）。

## 5. 檢查清單（每個接縫都要做）

```bash
python3 edit.py strip <切點秒數> --before 0.3 --after 0.5
```

- [ ] 接縫兩側的運動方向和速度延續
- [ ] 換世界時角色穿過了介面，介面有反應
- [ ] 硬切在拍點上（或標了 offbeat，且動作高點在拍點上）
- [ ] 切點前後沒有空幀、閃爍、物件跳動
- [ ] 尺度翻轉時版圖對得上（透鏡揭示前後的池塘、樹、巨人位置）
- [ ] 全片轉場語言統一：介面穿越為主，硬切為輔，不用溶解和特效轉場
