# 節奏、配樂、剪輯

## 1. 網格

基準片 **120 BPM**：一拍 0.5 s，一小節 2 s。30 fps 時一拍 15 幀，24 fps 時 12 幀，都能整除。

- 腳本裡：`ctx.beat(n)` = 全片第 n 拍（0 = 片頭）所在的本地幀；`ctx.g(秒)` = 全片秒數所在的本地幀。
- `build.py` 會在時間軸上每拍放一個標記（B12、B13…），外加 `CUT_IN`／`CUT_OUT`。

## 2. 切點規則

基準片 17 個切點裡 14 個落在拍點上；不在拍點上的 3 個都是**動作驅動**（甩鏡撞擊 28.37、果實落地 40.93、升到俯拍 51.9）。

1. 靜態、揭示、反應類的切點**卡拍**。
2. 動作中的切點**跟動作走**，標 `"offbeat": true`，但動作的高點（落地、撞擊、果實開始掉）要卡拍。
3. 重要動作也卡拍：落地、眨眼、轉身、點亮。連續跳躍一拍一跳。
4. 母題的動作就是拍子：游標一拍亮一拍暗。
5. `python3 edit.py check` 會列出每個切點偏離拍點多少毫秒。

## 3. 能量曲線（基準片的配樂結構）

```
 0– 2 s   幾乎無聲（−57 → −46 dB），零星點擊          游標閃爍
 2– 3.5   快速點擊（打字）                           游標開始「寫」
 4– 6.5   上行音高掃頻／琶音                          成形
 8–11.5   稀疏                                       房間、穿膜
12–28     主旋律進入，每拍有起音（−16～−21 dB）        旅程
28–39     收小、留白（−22～−28 dB）                   走進草原、種樹
40.0      全片最響的重拍（−13 dB）                     果實落下
40–48     八分音符脈衝                                分身湧動、堆砌巨人
48–52     維持高能量                                  巨人邁步
52–58     高頻閃爍上行掃頻                            拉出
59.5      收尾
```

設計原則：**進入新世界時收，奇觀時放**；安靜在前，爆發在後。

## 4. 配樂來源

Claude 不能試聽，也不能生成真正的音樂。選項（在參數卡上讓使用者選）：

1. **使用者提供或購買授權的曲子**（推薦）：120 BPM、40 s 左右有重拍。放 `assets/music.wav`，`audio.offset` 對齊第一拍。
2. **先剪後配**：照第 3 節的能量曲線寫一份配樂需求單給作曲者或音樂生成工具，拿回來再對拍。
3. 驗證：用頻譜圖和分段 RMS 檢查重拍位置（`ffmpeg -lavfi showspectrumpic`；或 Python 讀 wav 算每 0.5 s 的 RMS），並告訴使用者你沒辦法試聽。

## 6. 剪輯

```bash
python3 edit.py assemble            # 依 shots.json 取每個鏡頭 CUT_IN…CUT_OUT 的幀 + 音樂 → out/<slug>.mp4
python3 edit.py overview            # 全片縮圖
```

缺幀的鏡頭會以黑幀補上，粗剪隨時可以跑。全片硬切；需要調整切點時改 `shots.json` 的時間，重建該鏡頭（handles 讓前後各有 6 幀可以挪）。
