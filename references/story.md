# 敘事：九步配方、母題、尺度、能量

這類片子好看不是因為鏡頭多，而是因為**每個鏡頭都在推進同一個想法**。先把想法和結構做對，再談畫面。

## 1. 九步配方

基準片的結構，抽象成可以套到任何題材的九步。每一步標出它在基準片裡的位置。

| 步驟 | 要做的事 | 基準片 | 設計重點 |
|---|---|---|---|
| ① **源點符號** | 選介面裡最小、最常見的一個元素當種子 | 終端機的橘色游標 | 越小越日常越好；觀眾要一眼認得 |
| ② **符號成為角色** | 讓它長成角色：2D → 體素 → 實體三段形變 | 0–8s 游標打出像素圖，擠出成體素，融成黏土 | 一個長鏡頭完成；讓觀眾看到「深度出現」 |
| ③ **第一次尺度揭示** | 硬切到大遠景，主角變成一個點 | 8s 整個房間，Clawd 是螢幕上的橘點 | 一秒就夠，揭示比停留重要 |
| ④ **穿越介面** | 角色離開它的世界，穿過一層有物理反應的介面 | 10.5–12s 穿過螢幕玻璃光膜 | 介面要有反應：光、波紋 |
| ⑤ **旅程與點亮** | 在新世界裡移動，每一步都留下改變 | 12–28s 鍵盤上跳，踩過的鍵亮起來 | 改變要能累積（足跡會一直亮着） |
| ⑥ **第二次尺度翻轉** | 鑽進一個小東西，裡面是遼闊的世界 | 28s 跳進鍵帽，從天空掉進草原 | 進入時收音樂、加亮度：走進光裡 |
| ⑦ **母題回收** | 源點符號在新世界再次出現，被角色「使用」 | 32–36s 草裡的游標，被種下 | 角色要先「發現」它（轉身、停頓） |
| ⑧ **奇觀：一變多、多成一** | 種子長成能複製自己的東西，複製品組成更大的自己 | 36–48s 樹結出分身，分身拼成巨人 | 卡在全片最強的重拍；遞迴（巨人的每個體素都是完整的小 Clawd） |
| ⑨ **拉出回到起點** | 一鏡到底把所有尺度串起來，角色和自己的源頭對望，源點符號再次開始動作 | 52–59s 拉出鍵帽、鍵盤全亮、看著螢幕上的 2D 自己，游標又開始閃 | 世界要和開頭不一樣（被點亮了），符號要和開頭一樣（閉環） |

## 2. 母題設計

母題是一個**形狀**，不是一個物件。基準片的母題是「橘色豎直長方條」，它出現了五次，每次換一個身分：

| 時間 | 形態 | 身分 |
|---|---|---|
| 0s | 終端機游標（橘、亮、閃爍） | 起點 |
| 7.7s／11–12s | 遠處桌面上另一根橘色游標 | 伏筆（觀眾還不知道它的意義） |
| 32s | 草地裡立著的橘色游標 | 被發現的東西 |
| 36s | 從地裡升起的深色方柱（同比例） | 種子變成樹幹 |
| 59s | 螢幕上 2D 小怪旁邊的游標開始閃 | 終點 = 新的起點 |

**做法**：

1. 母題的比例固定（游標寬:高 ≈ 1:3），顏色或材質可以變（樹幹變成深色樹皮），觀眾仍然認得。
2. 第一次出現時給特寫，第二次放在遠處當伏筆（不解釋），第三次讓角色和它互動，最後一次回到開頭的狀態。
3. 母題的動作也要重複：游標的閃爍是 0.5 秒一次，正好一拍；結尾它又以同樣的節奏閃。

## 3. 尺度階梯

把全片的空間寫成一道階梯，觀眾要被翻轉至少兩次：

```
房間（大遠景，8s）
 └ 螢幕裡的終端機（角色 1.5 cm，0–11s）
    └ 鍵盤（角色站在鍵帽上，11–28s）
       └ 鍵帽裡的微縮地景（體素，從外面看）
          └ 鍵帽裡的草原（寫實，從裡面看：角色在草叢裡只有腳踝高，28–52s）
             └ 巨人（由幾百個完整的小角色組成，43–52s）
拉出：草原 → 鍵帽 → 鍵盤 → 螢幕（52–59s）
```

**規則**：

- 從大到小用**硬切**（8s：特寫 → 房間）；從外到內用**穿越**（螢幕玻璃、鍵帽表面）；從內到外用**一鏡到底的拉出**。
- 同一個世界的兩種解析度要**版圖對位**：寫實草原俯視的池塘、樹、巨人位置，和鍵帽裡的體素微縮版完全一樣（`shots.json` 的 `layout`）。
- 「裡面」的世界要比「外面」更亮、更大、更寫實：鑽進去等於走進光裡。

## 4. 換題材的方法

九步配方不綁定 Claude Code。換題材時替換三樣東西：**源點符號、外層世界、內層世界**。

| 題材 | 源點符號 | 外層世界（玩具尺度） | 內層世界（遼闊） | 奇觀 |
|---|---|---|---|---|
| Claude Code（基準） | 終端機游標 | 樹脂鍵帽鍵盤 | 鍵帽裡的草原 | 分身拼成巨人 |
| 筆記軟體 | 文字插入點／勾選框 | 一本攤開的筆記本，每頁是一片地形 | 某一頁裡的森林 | 勾選框長成藤蔓，結出清單項目 |
| 音樂 App | 播放鍵三角形 | 黑膠唱片上的溝槽城市 | 溝槽裡的峽谷 | 音符果實落下拼成樂器 |
| 地圖 App | 定位圖釘 | 桌上的立體地圖 | 圖釘插下去的那個小鎮 | 一個圖釘變成一條路線的人潮 |
| 相機 App | 快門圓點 | 鏡頭玻璃 | 鏡頭裡看到的風景 | 光點拼成一張照片 |

替換後角色規格（character.md）、鍵帽構造（keycaps.md 的容器原則）、轉場（transitions.md）、光影規則都照用。角色不是 Clawd 時，用 `character.py` 的 box rig 照樣建，只改 `BODY/ARMS/LEGS/EYES` 和 `SPRITE`。

## 5. 能量曲線與色彩腳本

先畫曲線，再排鏡頭。基準片：

```
亮度   ▁▁▂▂▃▃▃▃▃▃▃▃▃▃▅▇▇▇▇▇▇▇▇▇▇▇▇▇▇▇▇▅▃▂     （暗 → 部分亮 → 全亮 → 回到暗）
響度   ▁▂▃▃▃▃▅▅▅▅▅▅▅▅▃▃▃▃▃▃▇▇▇▇▇▇▇▅▅▅▅▃          （進新世界時收，奇觀時放）
時間   0    8   12        28        40        52    60
```

- **亮度**講故事：沉睡的世界 → 被點亮的足跡 → 寫實的陽光 → 全部醒來的鍵盤。
- **響度**和亮度錯開：28s 走進最亮的世界時音樂反而收小（留白），40s 奇觀時才爆發。對比才有力。
- **色彩**：環境永遠是冷色（藍、青、綠），橘色只屬於角色系統。每個段落換一個主色調（終端機：黑藍；鍵盤：黑藍＋各色鍵帽；草原：綠＋天藍）。

## 6. 鏡頭長度規則

- **長鏡頭（≥5 秒）給形變和奇觀**：誕生（8s）、穿屏落鍵（6s）、堆砌巨人（5s）、大拉出（7s）。觀眾需要時間看清變化。
- **短鏡頭（約 1 秒）給揭示和反應**：房間全景、分身落地、分身海。一秒就夠，揭示比停留重要。
- 長短交錯，不要連續三個同長度的鏡頭。
- 60 秒片約 17–18 個鏡頭（平均 3.5 秒）。片長變了就按比例增減鏡頭，不要把每個鏡頭拉長。

## 7. 角色怎麼演

角色沒有嘴、不說話，只用**注意力的方向**演戲：

- **發現**：停下 → 轉身（0.3–0.4 秒，`back` 緩動）→ 身體微傾（好奇）。
- **期待**：瞇眼（`squint`）、預備下蹲（`hop` 的預備動作）。
- **驚訝**：小幅壓扁再彈起（`squash` 0.1 → −0.05 → 0）。
- **仰望**：上身後仰（`tilt` pitch 負值），持續到事件結束。
- **陪伴**：奇觀發生時，角色放在前景一側看著它（觀眾透過角色的視線看奇觀）。

每個鏡頭至少一個表演動作；奇觀鏡頭裡角色是觀眾的代理人，不能消失。
