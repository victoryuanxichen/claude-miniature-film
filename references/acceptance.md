# 驗收標準：以基準片為尺

基準片《claude.MP4》就是驗收標準。這份文件把它拆成四層可以逐條打勾的檢查，**任何一層都不需要你主觀覺得「好看」**，只要和基準對照。

| 層 | 驗什麼 | 需要渲染嗎 | 工具 |
|---|---|---|---|
| **A 紙上驗收** | 分鏡、`shots.json`、鏡頭腳本的結構、時間、鏡頭參數 | **不需要** | 讀文件、`edit.py check` |
| **B 靜幀驗收** | 英雄幀的構圖、景別、光、事件 | 英雄幀（`previs` 就夠） | `edit.py compare` |
| **C 數值驗收** | 亮度、對比、飽和度、橘色佔比、冷色佔比、運動量 | 英雄幀或整個鏡頭 | `edit.py metrics` |
| **D 整片驗收** | 切點、節奏、能量曲線、轉場 | 整片（`previs` 就夠） | `edit.py check／strip／assemble` |

**還不能渲染時**（硬體不夠、使用者只要腳本）：做完 A 層就交付，並明說 B–D 層等渲染後再驗。

參考資料：`../benchmark/ref/<鏡號>_t<全片秒數>.jpg`（每個英雄幀一張，原片 1024×576）、`../benchmark/metrics.json`（數值指紋，由 `template/filmmetrics.py` 產生）、`../benchmark/sheets/`（全片 3 fps 拆幀）。用 `new_project.py` 建的專案會把它們複製到 `reference/`。

**新題材怎麼用**：每個鏡頭在 `shots.json` 加 `"ref": "S10"`，指定最接近的基準鏡頭（例如任何「草叢微距、角色走向鏡頭」都對照 S10）。比的是**做法和品質**，不是內容。

## B 層：靜幀驗收

```bash
blender -b -P build.py -- --shot S05 --stills hero --preset previs
python3 edit.py compare S05            # out/check/compare_S05_t13.50.jpg …（左：基準，右：你的）
```

用 Read 看每一張對照圖，逐項判斷「相符／不符」：

| 項目 | 相符的標準 |
|---|---|
| 景別 | 同一級（特寫／中景／遠景）；主體高度佔畫面比例在基準的 ±30 % 內 |
| 主體位置 | 主體中心落在和基準相同的三分格（左／中／右 × 上／中／下）裡，或有更好的理由 |
| 機位角度 | 仰／平／俯一致；地平線高度相近 |
| 景深 | 基準有前景虛化的，你也要有；焦點在同一個東西上 |
| 光 | 主光方向一致（例如草原都是左上方來的側逆光）；亮暗區塊分佈相近 |
| 色彩 | 主色調一致；橘色只在角色系統上 |
| 事件 | 這一幀正在發生的事和基準相同（例：13.5 s 是剛落在水鍵上、水花在鍵帽裡） |

一個英雄幀有 2 項以上「不符」就要改。不符但有更好的設計時，在交付報告裡說明理由。

## C 層：數值驗收

```bash
python3 edit.py metrics                # 有整段渲染時比整段，只有英雄幀時比基準的英雄幀
```

每個畫面縮成 64×36 後量 6 個數（定義見 `template/filmmetrics.py`）：

| 指標 | 意思 | 容差 | 超出時通常是 |
|---|---|---|---|
| `luma` | 平均亮度 0–255 | ±18 | 補光太多或曝光太高（太亮）；主光不夠或沒有自發光物（太暗） |
| `p90` | 亮部（第 90 百分位） | ±30 | 高光不夠亮（缺 bloom、自發光太弱）或過曝 |
| `sat` | 平均飽和度 | ±0.10 | AgX look 太淡或材質顏色太灰 |
| `orange` | 角色橘色佔畫面 % | ±6 | 角色在畫面裡太大或太小（相機距離、焦距不對） |
| `cool` | 冷色佔 % | ±12 | 環境色不對（終端機和鍵盤段應以冷色為主） |
| `motion` | 每步平均亮度變化 | ±4 | 運鏡太快或太靜（只在有整段渲染時比） |

每張卡：**參考幀**（`../benchmark/ref/`）、**必須做到**、**數值帶**（整段平均 luma / orange %）、**常見失敗**。

- 參考幀：`S01_t00.30`（游標＋虛化的 `>`）、`S01_t03.60`（完整 2D 像素圖、底部橘光）、`S01_t04.80`（網格可見的體素體）、`S01_t06.00`（倒角實體，3/4 視角）、`S01_t07.50`（走路、低機位）
