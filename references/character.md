# 角色：Clawd 的規格、rig 與表演

## 1. 造型規格（不准改比例）

以 Claude Code 啟動畫面的像素小怪為準。1 個像素 = `PX` = 1/6 BU（約 0.167 cm），主角身體寬 9 px = 1.5 cm。

```
      ..#########..      身體 9 × 6 px，深 6 px，倒角 0.45 px
      ..##.###.##..      眼睛 1 × 2 px，深色，在正面（−Y）
      ..##.###.##..
      #############      手臂 2 × 2 px 的方塊，深 2 px，在身體中段兩側
      #############
      ..#########..
      ...#.#.#.#...      腳 1 × 2 px；外側一對 = 前腳，內側一對 = 後腳
      ...#.#.#.#...
```

| 部件 | 盒子範圍（px，原點在腳底中心，−Y 是正面） |
|---|---|
| 身體 | x −4.5…4.5，y −3…3，z 2…8 |
| 手臂 | 左 x −6.5…−4.5，右 x 4.5…6.5；y −1…1；z 3…5 |
| 前腳 | x −3.5…−2.5 與 2.5…3.5；y −3…−2；z 0…2 |
| 後腳 | x −1.5…−0.5 與 0.5…1.5；y 2…3；z 0…2 |
| 眼睛 | x −2.5…−1.5 與 1.5…2.5；z 5…7；嵌在正面 |

**從正面看**，前腳在外、後腳在內，四隻腳排成一排，跟 2D 像素圖一致（基準片 9.5 s 的畫面就是這樣）。

**顏色**：亮面 `#cc6549`，背光 `#ac553c`，接近 Claude 品牌橘 `#d97757` 但偏紅、飽和度略低。眼睛 `#120c0b`。**沒有嘴。**

**材質**：軟陶／啞光軟膠（`materials.clay()`）：粗糙度 0.62、少量次表面散射（邊緣偏暖）、極細的表面顆粒、很淡的透明塗層。

## 2. 三種形態

| 形態 | 什麼時候 | 怎麼做 |
|---|---|---|
| **2D 像素** | 開場、結尾的螢幕上 | `voxel.sprite_points()` + `gn.reveal_group(Squash=1)`（3D 裡的平面）；螢幕上用 `env.screen_sprite()`（自發光像素） |
| **體素** | 成形過程、巨人 | `voxel.voxel_points(n=2)`：每個像素 2×2×2 個小方塊，看得見網格縫 |
| **黏土實體** | 主要形態 | `character.build()` 的 rig |

形變順序和時間見 [fx.md](fx.md) 第 1 節。

## 3. Rig

```
root（Empty，腳底中心）           移動、轉向（rotation_euler.z）、整體縮放
 ├ hip（Empty，高 2 px）          壓扁拉伸（scale）、彈跳（location.z）、傾身（rotation_euler）
 │  ├ body（mesh）
 │  ├ EyeL / EyeR（Empty，眼睛中心） 眨眼 = scale.z
 │  └ ArmL / ArmR（Empty，肩部）     揮手 = rotation_euler.y
 └ LegFL / LegFR / LegBL / LegBR（Empty，腳頂端，掛在 root 上）  擺腿 = rotation_euler.x
```

腳掛在 root 而不是 hip 上，所以身體壓扁時腳不會陷進地面。

- 建立：`rig = C.build('Clawd', loc, px=C.PX, facing_deg=0)`；之後用 `C.Rig.find('Clawd')` 找回來。
- 朝向：模型面向 −Y。要面向方向 (dx, dy)：`C.heading(dx, dy)`（弧度）；`common.yaw_to(a, b)` 回傳角度。
- 隱藏到某一幀才出現：`C.show(rig, 1, False); C.show(rig, f, True)`。

## 4. 表演庫（`mfilm.character`）

| 函式 | 做什麼 | 要點 |
|---|---|---|
| `place(rig, f, loc, yaw, ease)` | 在 f 幀放到 loc | 兩個 place 之間的曲線由第一個的 ease 決定 |
| `hop(rig, f0, f1, to, height, squash_amt, yaw_deg)` | 從目前位置跳到 to | 自帶：f0−4 預備、f0 下蹲、f0+2 拉長、空中收腿後仰、f1 落地壓扁、f1+3 回彈、f1+8 `back` 緩動回正 |
| `walk(rig, f0, path, speed, step, swing, bob)` | 沿路徑走 | 對角腿一組交替擺動、每步臀部上下、身體左右微晃；回傳結束幀 |
| `squash(rig, f, amount)` | 壓扁（正）／拉長（負） | 體積大致守恆 |
| `blink(rig, f)` | 眨眼 | 2 幀閉上、3 幀 `back` 張開 |
| `squint(rig, f0, f1, amount)` | 瞇眼（眼睛變成橫線） | 曬太陽、期待、懷疑 |
| `tilt(rig, f, roll, pitch)` | 傾身 | pitch 負 = 仰望，正 = 低頭看 |
| `turn(rig, f0, f1, yaw)` | 轉身 | 結尾 `back` 緩動，有一點過衝 |
| `wave(rig, f0, side, reps)` | 揮手 | |
| `legs_pose(rig, f, swing, tuck)` | 腳的姿勢 | tuck 1 = 空中收腿 |
| `idle(rig, f0, f1)` | 呼吸 | 任何靜止超過一秒的角色都要加，否則像死掉 |

## 5. 動作的物理感（一定要做到）

- **預備動作**：每次起跳前 4 幀先下蹲（`hop` 已處理）。轉身前可以先反方向微轉 2–3°。
- **壓扁拉伸**：起跳拉長、落地壓扁 0.2–0.3、回彈到 −0.06、再 `back` 回正。小跳用 0.15，從高處落下用 0.26。
- **弧線**：跳躍的根骨走拋物線（上升 `quad_out`、下降 `quad_in`），不要直線。
- **重量**：落地時鍵帽被按下（`keycap.press`）、地面揚起水花或光、角色腳底被下方的光染色。
- **節拍**：落地點放在拍點上；連續跳躍一拍一跳（基準片 20.5–23.0 s）。
- **時間差**：多個角色或多個部件不要同時開始、同時結束（腿比身體晚 1–2 幀）。

## 6. 尺度變體

| 用途 | px | 寬度 | 做法 |
|---|---|---|---|
| 主角 | 1/6 | 1.5 cm | `C.build()` |
| 分身（樹上的果實、分身雨、巨人的體素） | 0.48/9 ≈ 0.053 | 0.48 cm | `swarm.mini()`（合併成單一網格，供大量實例化） |
| 巨人 | 0.72（= 0.48 × 1.5） | 約 6.5 cm 身體 | `swarm.giant_rig()`：體素化 n = 1.5 格／px、只留外殼，約 680 個分身；每個部件的分身掛在對應的 rig 骨架上，所以 `walk/wave` 照用 |
| 鍵帽裡的微縮版 | 0.012 | 0.1 cm | `C.static_mesh(px=0.012)` 放在 `keycap.diorama_point()` |
| 房間全景裡的小點 | 0.07 | 0.6 cm | 自發光材質，讓它在大遠景裡讀得到 |

巨人的眼睛是「缺掉的格子」：外殼留洞，內部放一個深色方塊（`GiantCore`），所以眼洞看起來是黑的。

## 7. 換角色

不是 Clawd 時：改 `character.py` 的 `BODY/ARMS/LEGS/EYES` 盒子定義和 `voxel.py` 的 `SPRITE`，保持「方塊組成、正面朝 −Y、腳底在原點」三個約定，rig、表演、體素化、巨人全部照用。角色必須是**由盒子組成的簡潔造型**：這是 2D → 體素 → 實體形變成立的前提。
