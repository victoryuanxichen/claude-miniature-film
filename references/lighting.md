# 光影

## 1. 總原則

1. **每個光都有來源**：螢幕、太陽、天空、發光的鍵帽、種子、像素小怪。不准憑空補光讓畫面變亮。
2. **角色永遠有分離光**：暗場景用冷色輪廓光＋暖色底光（腳下發亮的鍵帽），亮場景用逆光邊緣。
3. **場景自己發光**：鍵帽、像素圖、紅光鍵、種子光點，同時是光源也是視線落點。
4. **用亮度講故事**：沉睡（暗）→ 足跡（部分亮）→ 陽光（全亮）→ 全部醒來（全亮）。
5. **冷暖分工**：環境冷、角色暖；只有重要事件才給暖光（成形時的橘光、種子的光點）。
6. **景深是光學預設值**：幾乎每個鏡頭都有前景虛化。

## 2. 五套燈光（`mfilm.lighting`）

能量是 1 BU = 1 cm、角色寬 1.5 BU 的起始值，**一律用 `look` 靜幀微調**。Blender 不會依單位縮放燈光衰減。

| 函式 | 場景 | 燈 | 起始值 |
|---|---|---|---|
| `rig_terminal(sc, subject)` | 終端機內部 | 頂部大面積柔光（主光）、後側冷色輪廓、低位前方弱補光、角色腳下的橘色點光（`glow`，平時 0，成形時打關鍵幀） | 9000 W／7000 W／900 W／0→400 W；世界 `#070b12` |
| `rig_room_night(sc, screen_center)` | 房間 | 螢幕面光（唯一主光）、窗外冷月光、桌面反彈 | 60000／40000／6000 W |
| `rig_keyboard(sc, center, monitor)` | 鍵盤 | 後上方的大面板（螢幕）、前方弱補光、側面冷色勾邊；鍵帽內點光由 `glow` 控制 | 90000／6000／9000 W |
| `rig_meadow(sc, elev, az)` | 草原 | 太陽（仰角 38°、方位 135°、強度 4.5、`#fff1dc`、角直徑 1.2°）＋物理天空（0.3）＋世界霧 | |
| `rig_endcard(sc, screen_center)` | 結尾 | 螢幕從前上方打光、低位冷輪廓 | 50000／5000 W |

光的動畫：`L.pulse(lamp, [(f, energy), …])`。

## 3. 各段的光（對照基準片）

**終端機內部**：主光在正上方偏前，角色頂面亮、底下一團柔和接觸陰影。2D 像素拼合時角色底部往地面打出一圈橘光（`glow` 0 → 250 → 400 → 0）。9.5 s 一道移動的白光掃過臉（S03 的 `Sweep` 燈從左移到右）：讓靜止的畫面也有事件。

**穿屏光膜**：光膜是半球形、邊緣最亮的白光（`fresnel_glow`），角色穿過時被切開。

**房間**：深夜，唯一主光是螢幕。低照度、高對比。

**鍵盤**：主光是後上方的螢幕，冷白偏藍，在每顆鍵帽頂面形成一條柔和白反光。每顆鍵帽裡的地景自己發光，光從樹脂溢出，把鄰鍵側壁染成同色；紅光鍵染紅周圍一圈。角色**冷頂暖底**：頂面被螢幕照成冷白，底面被腳下鍵帽染成粉橘。

**草原**：左上方暖陽，鏡頭常朝光拍，草葉邊緣透光發亮；遠景被藍白薄霧罩住；角色臉上有葉影（前景草葉擋光自然產生）；38.5 s 一道綠色光束斜穿樹冠（`FX.beam`）。

**結尾**：回到暗。螢幕從前上方打下冷光，螢幕上的 2D 小怪是自發光的橘色：「上：發光的 2D／下：受光的 3D」。

## 4. 世界與大氣

- `world_color(sc, color, strength)`：暗場景的環境色。
- `world_sky(sc, elev, az, strength)`：物理天空（Nishita；5.x 自動換成新天空模型，沒有就退回漸層）。**天空的太陽方向要和太陽燈一致**。
- `world_haze(sc, density=0.0006)`：世界體積霧，讓遠樹變藍灰。EEVEE 很便宜；Cycles 的世界體積很慢，改用 `haze_box()` 只包住看得到的範圍。

## 5. 色彩管理

`core.color_management()`：AgX ＋ Medium High Contrast。暗場景的曝光不要拉高，暗就要暗；用自發光物和輪廓光保持可讀性。

## 6. 常見問題

| 症狀 | 原因 | 處理 |
|---|---|---|
| 角色融進黑背景 | 沒有輪廓光 | 加大 `rim` 能量或把它移到更正後方 |
| 鍵帽像灰色塑膠片 | 背後沒有亮的東西可折射 | 讓後方有發光的鍵或螢幕；降低吸收 |
| 鍵帽裡的光照不出來（Cycles） | 外殼擋光（關了焦散） | 確認 `visible_shadow = False` |
| 草原死平 | 太陽在鏡頭背後（順光） | 讓太陽在鏡頭前側 30–60°（側逆光） |
| 遠景太清楚、沒有空氣感 | 霧太淡 | `world_haze` 密度加倍 |
| 發光物不夠「發光」 | 沒有 bloom | `look`／`final` 預設會加合成器 Glare；或提高自發光強度 |

## 7. 光影檢查

- [ ] 每個鏡頭說得出主光是什麼（螢幕／太陽／鍵帽）
- [ ] 角色在每個鏡頭都和背景分得開
- [ ] 發光物確實照亮了周圍（鄰鍵、角色腳底、草）
- [ ] 段落亮度符合能量曲線（暗 → 部分亮 → 全亮）
- [ ] 天空、太陽燈、陰影方向一致
