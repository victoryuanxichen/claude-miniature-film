# Claude Keycap World 分鏡（基準片復刻）

## 一句話

終端機的游標活過來變成 Clawd，走出螢幕、踩著封有世界的鍵帽前進，鑽進一顆鍵帽裡的草原，把游標種成一棵結滿自己的樹，分身拼成巨人；鏡頭一路拉出鍵帽回到終端機，螢幕上的游標又開始閃。

## 尺度階梯

```
房間（S02）
 └ 螢幕裡的終端機（S01、S03、S04）
    └ 鍵盤（S05–S08）
       └ 主角鍵帽裡的體素地景（S17 開頭從外面看）
          └ 鍵帽裡的寫實草原（S09–S16，角色只到草的腳踝）
             └ 巨人由約 680 個完整的小 Clawd 組成（S15–S16）
拉出：草原 → 鍵帽 → 鍵盤 → 螢幕（S16 結尾到 S17）
```
